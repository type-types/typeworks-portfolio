작업 방식

같은 결과를 바라보도록,
함께 정하고 확인합니다.

좋은 제작은 요구를 이해하는 것과 명확하게 전달하는 것에서 시작합니다.

함께 확인하는 네 단계

무엇을 정하고,
무엇을 받는지 명확하게.

01 / 04

필요를 이해합니다

지금 하는 일, 불편한 점과 원하는 결과를 함께 살펴봅니다. 대화와 자료에서 필요한 일을 찾습니다.

  • 현재 사용하는 도구와 일이 흐르는 방식 확인
  • 사용자와 운영자에게 필요한 기능 정리

범위를 합의합니다

만들 기능, 완료 기준, 비용, 일정과 수정 범위를 정합니다. 제작에 들어가기 전에 기준을 맞춥니다.

  • 납품할 기능과 산출물, 완료 기준 확정
  • 견적, 일정, 수정과 운영 안내 범위 합의

만들며 확인합니다

작동하는 화면을 공유하고 합의한 기준으로 함께 확인합니다. 작동하는 결과물을 보면서 조정합니다.

  • 진행한 작업, 결정할 내용과 다음 작업 공유
  • 실제 화면으로 기능 확인 및 피드백 반영

운영 방법을 전합니다

결과물을 전달하고 내용 수정과 운영 방법을 쉽게 알려드립니다. 전달받은 뒤에도 직접 이어가도록 돕습니다.

  • 합의한 결과물과 운영 자료 전달
  • 실제 화면으로 내용 수정과 운영 방법 안내

추가로 필요한 일이 생기면,
범위와 일정을 다시 정합니다.

합의한 수정과 새 기능 요청을 구분해 안내합니다. 변경할 내용과 비용, 일정에 합의한 뒤 작업에 반영합니다.

기획서가 없어도 상담할 수 있나요?+

지금 어떤 일을 하고 계신지, 어디에서 불편함이 생기는지부터 말씀해 주세요. 필요한 기능과 제작 범위를 함께 구체화합니다.

제작 후 수정하는 방법도 알려주시나요?+

내용 변경과 데이터 확인 등 합의한 운영 범위에 맞춰 실제 화면으로 안내합니다. 방법을 쉽고 간단하게 설명하는 것까지 제작 범위에 포함해 정합니다.

수정 횟수와 제작 기간은 어떻게 정하나요?+

기능 수, 화면과 연동 범위를 살펴보고 견적 단계에서 정합니다. 확정한 기준을 바탕으로 중간 확인과 납품을 진행합니다.
