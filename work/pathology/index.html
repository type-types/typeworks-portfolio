연구와 데이터

병리 이미지 편집 도구

이미지를 배치하고 관심 영역을 표시해 주석과 함께 저장하는 도구입니다.

담당 역할

프론트엔드 이미지 편집 기능 개발 및 API 연동

진행 상태

연구 프로젝트 참여

필요했던 것

연구자가 여러 이미지를 정렬하고 관심 영역을 표시한 뒤, 이미지와 주석 정보를 함께 관리할 작업 화면이 필요했습니다.

만든 것과 맡은 일

  • 캔버스에서 이미지를 이동하고 회전하며 배치하는 편집 기능을 구현했습니다.
  • 선택과 삭제, 실행 취소 등 편집 과정에 필요한 동작을 다듬었습니다.
  • 이미지와 주석 정보를 저장하고 다시 불러오도록 서버와 연결했습니다.

결과

이미지 편집과 저장 기능을 연결했습니다. 관련 연구는 2025 한국디지털콘텐츠학회 논문경진대회 동상을 받은 연구팀의 성과입니다.
