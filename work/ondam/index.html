01 / THE NEED

무엇이 필요했나요?

AI 대화 아이디어를 전화 연결부터 대화 기록 확인까지 이어지는 작동 가능한 서비스로 구체화할 필요가 있었습니다.

02 / THE WORK

어떻게 만들었나요?

  1. AI가 전화를 걸고 상대방과 대화하는 통화 흐름을 구현했습니다.
  2. 통화 내용을 기록하고 이전 대화 정보를 연결하는 기능을 만들었습니다.
  3. 실제 전화로 흐름을 검증하고 기록 처리와 중복 이벤트 처리 문제를 수정했습니다.
03 / THE RESULT

무엇을 전달했나요?

실제 통화로 전화 연결과 대화, 기록 흐름을 검증했습니다. KDB 소셜임팩트 아이디어 공모전 IR 우수상을 받은 프로젝트입니다.
