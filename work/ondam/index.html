AI 제품

온담 AI 안부전화

AI가 전화를 걸어 대화하고 통화 내용을 기록하는 프로토타입입니다.

담당 역할

풀스택 프로토타입 개발

진행 상태

프로토타입, 실제 통화 검증

필요했던 것

AI 대화 아이디어를 전화 연결부터 대화 기록 확인까지 이어지는 작동 가능한 서비스로 구체화할 필요가 있었습니다.

만든 것과 맡은 일

  • AI가 전화를 걸고 상대방과 대화하는 통화 흐름을 구현했습니다.
  • 통화 내용을 기록하고 이전 대화 정보를 연결하는 기능을 만들었습니다.
  • 실제 전화로 흐름을 검증하고 기록 처리와 중복 이벤트 처리 문제를 수정했습니다.

결과

실제 통화로 전화 연결과 대화, 기록 흐름을 검증했습니다. KDB 소셜임팩트 아이디어 공모전 IR 우수상을 받은 프로젝트입니다.
