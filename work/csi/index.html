CSI 데이터 수집과 라벨링 도구

연구에 필요한 데이터를 모으고 의미를 붙이는 작업 흐름

와이파이 신호를 이용한 재실 및 낙상 감지 연구팀이 데이터를 수집하고 라벨을 붙일 수 있는 도구를 만들었습니다.

담당 역할

데이터 수집 및 라벨링 도구 풀스택 개발, 시연 영상 제작

제품의 데이터 흐름을 설명한 도식입니다.

01 / THE NEED

무엇이 필요했나요?

센서 신호와 실제 행동을 함께 기록하고, 연구자가 시간대별 행동을 확인해 학습용 라벨을 붙일 작업 환경이 필요했습니다.

02 / THE WORK

어떻게 만들었나요?

  1. 센서 데이터와 카메라 영상을 같은 시간 기준으로 수집하는 흐름을 만들었습니다.
  2. 실험 데이터를 저장하고 수집 상태와 누락 여부를 확인하는 기능을 연결했습니다.
  3. 타임라인에서 행동을 확인하고 구간별 라벨을 작성하는 화면을 구현했습니다.
03 / THE RESULT

무엇을 전달했나요?

실시간 수집, 저장, 라벨링과 수집 품질 확인 기능을 구현했습니다. 관련 팀 프로젝트 CSI-Guard는 ICT AWARD KOREA 2026 은상을 받았습니다.
