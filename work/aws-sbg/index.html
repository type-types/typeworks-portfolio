담당 역할

진행 상태

세션 진행 / 홍보 자료 제작

강의와 실습 자료.

AWS 운영 입문과 CloudWatch 개념을 설명하는 발표 자료입니다.

AWS 운영 입문↗CloudWatch 개념 설명↗로그, 지표와 알람 이해하기↗

인스타그램 홍보 콘텐츠.

기존 커뮤니티 활동 사진과 모집 정보를 활용한 5기 모집 피드용 디자인 시안입니다.

인스타그램 홍보 시안 1↗인스타그램 홍보 시안 2↗인스타그램 홍보 시안 3↗인스타그램 홍보 시안 4↗

필요했던 것

참여자가 AWS 운영 개념을 이해하고 실습할 수 있는 자료와, 커뮤니티 활동을 알릴 홍보 콘텐츠가 필요했습니다.

만든 것과 맡은 일

  • CloudWatch 공동 진행과 Cost Explorer, Budgets 설명을 맡고 강의 및 실습 자료를 준비했습니다.
  • 기술 개념과 확인 순서를 슬라이드와 실습 안내로 정리했습니다.
  • 커뮤니티 활동과 모집 정보를 인스타그램 피드용 캐러셀 시안으로 제작했습니다.

결과

AWS SBG 세션을 진행하고 강의 및 실습 자료를 제작했습니다. 5기 모집을 안내하는 인스타그램 홍보 시안도 만들었습니다.
