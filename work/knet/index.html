필요했던 것

지원서 접수 이후 면접과 합격 안내, 회비 확인까지 이어지는 모집 과정을 관리할 도구가 필요했습니다.

만든 것과 맡은 일

  • 지원자와 운영진이 각각 해야 할 일을 모집 단계별로 정리했습니다.
  • 지원서 작성과 문의 접수, 지원 상태 확인 기능을 만들었습니다.
  • 운영진이 면접과 합격, 회비 확인 상태를 관리하도록 관리자 기능을 연결했습니다.

결과

동아리의 공개 웹사이트와 모집 및 회원 관리 기능을 제작해 실제 운영에 사용했습니다.
