업무 운영실제 운영

K-NET

모집부터 회원 관리까지 이어지는 동아리 운영 도구

동아리 소개와 모집, 지원자 관리, 회원 정보를 하나의 웹사이트에 연결했습니다.

담당 역할

운영 요구 정리 및 웹사이트 개발

K-NET실제 제품 화면
01 / THE NEED

무엇이 필요했나요?

지원서 접수 이후 면접과 합격 안내, 회비 확인까지 이어지는 모집 과정을 관리할 도구가 필요했습니다.

02 / THE WORK

어떻게 만들었나요?

  1. 지원자와 운영진이 각각 해야 할 일을 모집 단계별로 정리했습니다.
  2. 지원서 작성과 문의 접수, 지원 상태 확인 기능을 만들었습니다.
  3. 운영진이 면접과 합격, 회비 확인 상태를 관리하도록 관리자 기능을 연결했습니다.
03 / THE RESULT

무엇을 전달했나요?

동아리의 공개 웹사이트와 모집 및 회원 관리 기능을 제작해 실제 운영에 사용했습니다.
