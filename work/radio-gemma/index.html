Radio-gemma 학습 시스템

판독 사례를 비교하고 피드백을 확인하는 전공의 학습 시스템입니다.

담당 역할

프론트엔드 개발 및 API 연동

진행 상태

연구 프로젝트 참여

필요했던 것

전공의가 예비 판독과 최종 판독을 비교하고, 학습에 필요한 분석과 사례를 확인할 화면이 필요했습니다.

만든 것과 맡은 일

  • 판독 사례와 비교 결과를 확인할 수 있는 화면을 구성했습니다.
  • 분석 결과와 북마크, 메모 등 학습 기능을 서버와 연결했습니다.
  • 분석 대기 상태와 날짜 및 검사 종류 필터를 다듬어 작업 흐름을 명확히 했습니다.

결과

학습 화면과 API 연동에 참여했습니다. 관련 연구의 HCI 인간공학회 및 AOCR 2026 싱가포르 발표는 연구팀의 성과입니다.
