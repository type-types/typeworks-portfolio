공연 참여 기능을 설명한 도식입니다.

01 / THE NEED

무엇이 필요했나요?

공연 중 관객의 참여를 받고, 진행자가 곡과 참여 이벤트를 관리할 수 있는 도구가 필요했습니다.

02 / THE WORK

어떻게 만들었나요?

  1. 관객이 현재 곡을 확인하고 반응과 메시지를 남기는 화면을 만들었습니다.
  2. 참여 현황과 순위, 추첨 기능을 공연 진행에 연결했습니다.
  3. 운영자가 곡과 이벤트를 관리하도록 관리자 화면을 만들고 현장 사용 후 피드백을 반영했습니다.
03 / THE RESULT

무엇을 전달했나요?

2026년 1월 17일 Club FF 공연에서 관객 참여 기능을 사용했습니다. 공연 후 접속 안내와 참여 기능, 관리자 화면의 개선 사항을 정리하고 수정했습니다.
